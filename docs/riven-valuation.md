# 紫卡首版估价规则

规则版本：`sample-heuristic-v1`。估价只使用当前武器批次的真实一口价挂单样本，价格区间表示挂牌参考，不代表成交价，也不提供高置信度成交预测。

候选样本要求为有限、非重复词条，且为 2–3 个正面词条、最多 1 个负面词条。目标紫卡先通过本地 `riven_analysis::analyze` 校验；越界直接不可用，未知词条或缺少强化等级（`mod_rank`）只会降低数值覆盖，不会当作数值为零。样本按当前武器池内正面词条频率学习热门度，按相似度优先选择同布局高匹配卡，再回退到最佳相似度差不超过 0.15 的最近卡。

相似度具体为 `S = 0.8 * weightedJ + 0.1 * layout_match + 0.1 * negative_match`，其中 `weightedJ` 使用当前池的词条频率权重。3 正面 + 1 负面布局使用 `damage` 偏好，2 正面 + 1 负面使用 `extreme` 偏好；匹配到对应真实 catalog `gameRef` 的词条使用 1.2 category boost。该 boost 只影响当前武器批次的热门度调整，不把全武器热门词条硬套到每个武器。

每张参考卡的相似度权重为 `w = (0.1 + similarity)^3`。其价格先乘热门度因子、数值因子和周热度因子，再用这些权重取加权中位数；顶层 `popularity_factor`、`numeric_factor`、`numeric_coverage` 与 `heat_factor` 也使用同一组 `w` 加权，保证与 `adjusted_price` 使用的因子一致。周热度按当前周统计组的最大 `pop` 计算 `1 + 0.02 * pop / 100`（例如 `40` 和 `50` 得 `1.01`，不会相加）。

数值调整会先按双方 `mod_rank + 1` 做 per-rank normalization；`multiply` 单位使用 `abs(value - 1)`，其他单位使用绝对值，再比较对数比值。最终为 `exp(0.35 * weighted_mean)`，并限制在 0.8–1.25；不支持、缺少段位或无法对应的数值会跳过而不是当作零。源码中的主要阈值集中在 `riven_valuation.rs` 常量：相似阈值 0.8、相似度布局/负面加分 0.1、nearest 最大相似度差 0.15、热门度指数系数 0.30（因子范围 0.75–1.35）、周热度系数 0.02，以及区间半宽 15%/25%/40%。满足“相似、池至少 20 张、至少 3 张参考、数值覆盖至少 50%、样本未过期”时为中置信度并使用 15%。样本过期额外加 10 个百分点，覆盖不足额外加 5 个百分点，最高 60%。覆盖率低于 1 时会明确警告部分数值未比较；警告也会明确参考不足、nearest 回退、负面词条不一致和样本过期。

热门度 `p` 来自当前武器批次中所有有效一口价样本的词条频率，不是按价格排序后取前 N 张。`price_desc` 仅表示本次批次结果按价格降序展示；它不是全市场排序，也不是成交价或成交统计。

模型常量位于 `src-tauri/src/riven_valuation.rs`，便于后续用成交数据校准。当前区间会在样本过少、缓存过期或数值覆盖不足时扩大，并始终标注为挂牌价格参考。首版尚无成交回测校准，不代表市场公允价或官方公式。
